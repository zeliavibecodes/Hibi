# Hibi 日々

One place to log Japanese practice time, the things I finish, and days in Yugawara. A calendar shows what happened each day; Tracked shows totals for the week, month and year.

Open https://zeliavibecodes.github.io/Hibi/ in Safari, then Share › Add to Home Screen.

Entries are saved on the phone. In Settings you can connect a private GitHub Gist so they sync between devices, and export or import a backup file.

## Home Screen widget

`widget/hibi-widget.js` is a large widget for the Scriptable app: today's date, this month shaded by practice time, and three jpdb words to review each day. Save it to iCloud Drive › Scriptable, run it once in Scriptable to add your GitHub and jpdb keys, then add a large Scriptable widget and choose this script.
